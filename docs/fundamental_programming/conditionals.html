Conditionals#

Learning outcomes

After working through this topic, you should be able to:

  1. use conditionals to organise decisions in program code

  2. explain how comparisons and the commands if, elif, and else control what a program does

  3. use compound code containing conditionals to illustrate and solve problems in chemistry and molecular science

    print("The solution is basic.")

if pH < 7:
    print("The solution is acidic.")
else:
    print("The solution is not acidic.")

pH = 5.5

if pH < 7:
    print("The solution is acidic.")

    print("The solution is neutral.")

Definition#

Conditional

A conditional is a logical test used to determine whether a criterion is satisfied. If the criterion is satisfied, an action is performed. If it is not satisfied, that action is not performed. In Python, such a decision normally begins with if.

Conditionals are central to programming and to scientific reasoning. We often draw conclusions that depend on one or more measured or calculated quantities: if the pH is below a threshold, we classify a solution in one way; if an absorbance lies outside a calibration range, the sample may need to be diluted or measured again; if a reaction quotient is smaller than the equilibrium constant, the system will move in one direction towards equilibrium.

A program can apply such decisions consistently, but we must decide which criteria are scientifically meaningful. A conditional is therefore also a way of making our scientific assumptions explicit.

For a simplified example near 25 °C, we may call a solution acidic if its pH is below 7. In pseudocode:

if pH is less than 7:
    classification = "acidic"
otherwise:
    classification = "not acidic"

The Python structure is very similar:

if pH < 7:
    classification = "acidic"
else:
    classification = "not acidic"

Conditionals in Python#

Let us return to the pH example and make the pH user input:

pH = float(input("Enter the pH value: "))

if pH < 7:
    print("The solution is acidic.")

The program asks the user for a pH value and converts it to a float. A conditional begins with if, followed by a logical test. Here we test whether the pH is less than 7. If the test is true, the message is printed. A colon follows the test, and everything belonging to the conditional is indented. If the test is false, nothing happens.

The test itself always has one of the Boolean values True or False:

pH = 5.5
print(pH < 7)   # Prints True
print(pH > 7)   # Prints False

If we want something to happen when the test is false, we can add else:

pH = float(input("Enter the pH value: "))

if pH < 7:
    print("The solution is acidic.")
else:
    print("The solution is not acidic.")

We can add further criteria with elif, short for else if:

pH = float(input("Enter the pH value: "))

if pH < 7:
    print("The solution is acidic.")
elif pH > 7:
    print("The solution is basic.")
else:
    print("The solution is neutral.")

If pH is neither below nor above 7, it follows logically that it is 7, so else needs no further test. If we do want to test equality explicitly, we use ==:

if pH == 7:
    print("The pH value is exactly 7.")

== tests whether two values are equal. A single equals sign (=) assigns a value to a variable. The comparison operators are summarised below.

Some important points:

  • Indented statements are executed only when the test above them selects that branch. Indentation is part of Python’s structure, not decoration.

  • elif tests another criterion, while else is used if none of the preceding criteria are true.

  • Only the first true branch in one continuous if–elif–else structure is executed. The order of the tests can therefore affect the result.

  • A conditional must begin with if; elif and else are optional.

  • A new if begins a new, independent test.

When numbers are almost equal#

Measured and calculated floating-point values are rarely exact. A pH that should theoretically be 7 might, for example, be stored as 6.999999999. The test pH == 7 would then be false. It is often better to test whether the value lies within a reasonable tolerance:

pH = 6.99
tolerance = 0.01

if abs(pH - 7) <= tolerance:
    print("The solution is approximately neutral.")

The appropriate tolerance depends on measurement uncertainty and the purpose of the calculation. In addition, the pH of a neutral solution depends on temperature. Treating pH 7 as neutral is therefore an approximation appropriate near 25 °C.

Compound conditions#

Sometimes several criteria must be considered at once. We can combine tests using and, or, and not.

Operator

Meaning

and

Both criteria must be true

or

At least one criterion must be true

not

Reverses a Boolean value

Suppose an analytical method has a recommended absorbance range from 0.10 to 1.00. We can test whether a measurement lies in the range like this:

absorbance = 0.82

if absorbance >= 0.10 and absorbance <= 1.00:
    print("The measurement is within the recommended range.")
else:
    print("Consider adjusting the sample or measurement conditions.")

Python also lets us write the same test as a chained comparison:

if 0.10 <= absorbance <= 1.00:
    print("The measurement is within the recommended range.")

The numerical limits are only an example. The valid range must be determined from the actual instrument, calibration, and analytical method. With or, we can test whether the absorbance lies outside the range:

if absorbance < 0.10 or absorbance > 1.00:
    print("The measurement is outside the recommended range.")

Exercise

Gibbs free energy, \(\Delta G\), can be used to assess whether a process is thermodynamically favoured under specified conditions. Complete the program so that it distinguishes negative, positive, and approximately zero free energy. Use a tolerance of 0.01 kJ/mol around zero.

delta_G = float(input("Enter ΔG in kJ/mol: "))
tolerance = 0.01

# Write the conditional here

Suggested solution

delta_G = float(input("Enter ΔG in kJ/mol: "))
tolerance = 0.01

if delta_G < -tolerance:
    print("The process is thermodynamically favoured in the forward direction.")
elif delta_G > tolerance:
    print("The process is not thermodynamically favoured in the forward direction.")
else:
    print("The system is approximately at equilibrium.")

The sign of \(\Delta G\) describes the thermodynamic driving force under the specified conditions, not how rapidly the process occurs.

Nested conditionals#

A conditional can contain another conditional. This is useful when a second decision is relevant only if an earlier criterion has been satisfied. Each new level receives additional indentation.

The example below performs a simplified quality check of a spectrophotometric measurement. The absorbance is assessed only if the measurement has already been blank-corrected.

blank_corrected = input("Has the measurement been blank-corrected (yes/no)? " ).strip().lower()

if blank_corrected == "yes":
    absorbance = float(input("Enter the absorbance: "))

    if 0.10 <= absorbance <= 1.00:
        print("The measurement is within the recommended range.")
    else:
        print("Consider diluting the sample or changing the measurement conditions.")
elif blank_corrected == "no":
    print("Blank-correct the measurement before assessing the absorbance.")
else:
    print("Please answer 'yes' or 'no'.")

The inner if–else structure belongs to the first branch and is therefore considered only when the user answers yes. The methods strip() and lower() remove surrounding whitespace and convert the text to lower case. Thus, for example, Yes is interpreted as yes.

Nested structures are useful when tests genuinely depend on one another, but too many levels make code difficult to read. In that case, it may be better to divide the problem into several steps or use compound conditions.

Exercises#

Exercise 3.1

Explain why the two programs below print different temperatures. What is printed in each case?

temperature = 25

if temperature > 20:
    temperature = temperature + 5

temperature = temperature + 2
print(temperature)

temperature = 25

if temperature > 20:
    temperature = temperature + 5
else:
    temperature = temperature + 2

print(temperature)

Suggested solution

The temperature is above 20, so both programs execute temperature = temperature + 5. In the first program, temperature = temperature + 2 lies outside the conditional and is therefore always executed, giving 32. In the second program, the same calculation belongs to else and is skipped because the if condition is true, giving 30.

Exercise 3.2

Write a program that takes temperature, melting point, and boiling point as input and reports whether a substance is solid, liquid, or gaseous. Give a separate message when the temperature is exactly equal to the melting point or boiling point. This is a simplified model for a pure substance at a specified pressure; at a phase transition, two phases can coexist.

Suggested solution

temperature = float(input("Temperature in °C: "))
melting_point = float(input("Melting point in °C: "))
boiling_point = float(input("Boiling point in °C: "))

if temperature < melting_point:
    print("The substance is solid.")
elif temperature == melting_point:
    print("The substance is at its melting point.")
elif temperature < boiling_point:
    print("The substance is liquid.")
elif temperature == boiling_point:
    print("The substance is at its boiling point.")
else:
    print("The substance is gaseous.")

Exercise 3.3

For this exercise, an analytical method has a recommended absorbance range from 0.10 to 1.00. Write a program that takes absorbance as input and distinguishes four cases: invalid negative value, absorbance too low, absorbance within the recommended range, and absorbance too high.

Suggested solution

absorbance = float(input("Enter the absorbance: "))

if absorbance < 0:
    print("Absorbance cannot be negative in this model.")
elif absorbance < 0.10:
    print("The absorbance is below the recommended range.")
elif absorbance <= 1.00:
    print("The absorbance is within the recommended range.")
else:
    print("The absorbance is above the recommended range.")

Notice that we do not need to test the lower limit again in the third branch. If Python reaches that branch, the earlier tests have already ruled out negative values and values below 0.10.

Exercise 3.4

Take the reaction enthalpies of two reactions as input. Print which reaction is more exothermic, or whether the reaction enthalpies are equal. Remember that the more exothermic reaction has the more negative \(\Delta H\).

Suggested solution

delta_H1 = float(input("ΔH for reaction 1 in kJ/mol: "))
delta_H2 = float(input("ΔH for reaction 2 in kJ/mol: "))

if delta_H1 < delta_H2:
    print("Reaction 1 is more exothermic.")
elif delta_H2 < delta_H1:
    print("Reaction 2 is more exothermic.")
else:
    print("The reactions have the same reaction enthalpy.")

Exercise 3.5

For a reaction, compare the reaction quotient \(Q\) with the equilibrium constant \(K\). Take positive values for \(Q\) and \(K\) as input and report whether the system will shift towards products (\(Q<K\)), towards reactants (\(Q>K\)), or is at equilibrium (\(Q=K\)).

Suggested solution

Q = float(input("Enter the reaction quotient Q: "))
K = float(input("Enter the equilibrium constant K: "))

if Q < K:
    print("The system shifts towards products.")
elif Q > K:
    print("The system shifts towards reactants.")
else:
    print("The system is at equilibrium.")

Exercise 3.6

Modify Exercise 3.5 so that the system is treated as approximately at equilibrium when the relative deviation between \(Q\) and \(K\) is at most 1%, assuming \(K>0\): \(|Q-K|/K\).

Suggested solution

Q = float(input("Enter the reaction quotient Q: "))
K = float(input("Enter the equilibrium constant K: "))
relative_deviation = abs(Q - K) / K

if relative_deviation <= 0.01:
    print("The system is approximately at equilibrium.")
elif Q < K:
    print("The system shifts towards products.")
else:
    print("The system shifts towards reactants.")

The approximate-equilibrium test must come first; otherwise almost every value is captured by Q < K or Q > K before the tolerance is considered.

Exercise 3.7

Create a simple amount-of-substance calculator based on \(n=m/M\). The user should choose whether to calculate amount (n), mass (m), or molar mass (M). Ask for the two required quantities, perform the appropriate calculation, and print the answer with a unit.

Suggested solution

choice = input("What would you like to calculate (n, m, or M)? " ).strip()

if choice == "n":
    mass = float(input("Mass in g: "))
    molar_mass = float(input("Molar mass in g/mol: "))
    amount = mass / molar_mass
    print(f"The amount of substance is {amount:.3f} mol.")
elif choice == "m":
    amount = float(input("Amount of substance in mol: "))
    molar_mass = float(input("Molar mass in g/mol: "))
    mass = amount * molar_mass
    print(f"The mass is {mass:.3f} g.")
elif choice == "M":
    mass = float(input("Mass in g: "))
    amount = float(input("Amount of substance in mol: "))
    molar_mass = mass / amount
    print(f"The molar mass is {molar_mass:.3f} g/mol.")
else:
    print("Invalid choice. Enter n, m, or M.")

Write a program that takes the wavelength of visible light in nm and reports the approximate colour. You may extend it to other parts of the electromagnetic spectrum. Boundaries between colours are approximate and vary between sources.

wavelength = float(input("Enter the wavelength in nm: "))

Exercise 3.9

Take the concentration of \(H_3O^+\) as input and calculate pH using \(pH=-\log_{10}[H_3O^+]\). Then report whether the solution is acidic, basic, or approximately neutral, using a tolerance of 0.01 pH units around pH 7. Test with \([H_3O^+]=1\times10^{-7}\) mol/L. This simplified exercise treats pH 7 as neutral, corresponding approximately to 25 °C.

Suggested solution

from math import log10

hydronium = float(input("[H3O+] in mol/L: "))

if hydronium <= 0:
    print("The concentration must be greater than zero.")
else:
    pH = -log10(hydronium)
    tolerance = 0.01
    if abs(pH - 7) <= tolerance:
        print(f"pH = {pH:.2f}. The solution is approximately neutral.")
    elif pH < 7:
        print(f"pH = {pH:.2f}. The solution is acidic.")
    else:
        print(f"pH = {pH:.2f}. The solution is basic.")

Exercise 3.10

A buffer is usually most effective within roughly \(pK_a\pm1\). Take \(pK_a\) and the desired pH as input and report whether the pH lies within this approximate buffer range. Extend the program so that it also reports whether the pH is below or above the range.

Suggested solution

pKa = float(input("Enter pKa: "))
pH = float(input("Enter the desired pH: "))
lower_limit = pKa - 1
upper_limit = pKa + 1

if lower_limit <= pH <= upper_limit:
    print("The pH lies within the approximate buffer range.")
elif pH < lower_limit:
    print("The pH is below the approximate buffer range.")
else:
    print("The pH is above the approximate buffer range.")
