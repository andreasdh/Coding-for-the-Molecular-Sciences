Coding for the Molecular Sciences#

A practical introduction to Python programming, data handling, visualisation, statistics, and molecular-science applications.

The material is intended for students and scientists in chemistry and related molecular sciences who want to use programming as a tool for scientific reasoning rather than as an end in itself.

The online book covers:

  • getting started with Python and Visual Studio Code;

  • variables, data types, lists, conditionals, loops, functions, and data collections;

  • interactive programming exercises and quizzes;

  • scientific Python libraries and molecular visualisation;

  • reading, cleaning, visualising, and analysing experimental data;

  • basic statistics, calibration, statistical inference, and machine learning in molecular-science contexts.

The site is built automatically with Jupyter Book and published with GitHub Pages.

Author: Andreas Haraldsrud
