Data collections#

Learning outcomes

After working through this topic, you should be able to:

  1. create different NumPy arrays

  2. perform vector operations with arrays

  3. explain what tuples are and when they are useful

  4. create and use dictionaries

Python provides several ways to organise data. The most important collections for our purposes are:

  1. lists – flexible ordered collections that may contain similar or different kinds of data;

  2. arrays – numerical collections that support efficient element-wise and vectorised calculations;

  3. tuples – ordered collections that cannot be changed after they are created;

  4. dictionaries – collections that associate keys with values.

We have already worked with lists. We now turn to arrays, tuples, and dictionaries.

Arrays#

NumPy arrays are particularly important in scientific programming. They may look similar to lists, but numerical operators behave differently.

import numpy as np

list1 = [1, 2, 3]
list2 = [2, 3, 1]

print("List addition:", list1 + list2)

array1 = np.array(list1)
array2 = np.array(list2)

print("Array addition:", array1 + array2)

Exercise

Use the code above to explain the difference between list addition and array addition.

Suggested solution

Adding two lists concatenates them: the second list is placed after the first. Adding two NumPy arrays of the same shape performs element-wise addition: [1+2, 2+3, 3+1]. This is analogous to vector addition.

For a two-dimensional array called data, we use two indices: the first selects the row and the second selects the column. A colon selects all entries along that dimension.

print(data[1, :])  # every column in row 1
print(data[:, 0])  # column 0 from every row

For the table in the exercise:

])
print(data[:, 2])
print(data[2, 2])

Mathematics with arrays#

Arrays can behave like mathematical vectors or matrices. For example,

\[\vec{v}=[1,4,5]\]

and a matrix can be represented as a two-dimensional array. We will not develop matrix algebra here, but it is useful to recognise that multidimensional numerical objects map naturally onto NumPy arrays.

Vectorisation#

One of the main advantages of arrays is that operations can be applied efficiently to all elements at once. Vectorisation means expressing calculations as array operations instead of repeating scalar operations in explicit Python loops. Array addition is a simple example.

Tuples#

A tuple is an ordered collection whose elements cannot be reassigned after the tuple has been created. This is useful for values that belong together and should remain fixed. One simple example is an RGB colour code, where red, green, and blue intensities are stored together. Tuples use parentheses rather than square brackets.

black = (0, 0, 0)
white = (255, 255, 255)
red = (255, 0, 0)
magenta = (255, 0, 255)

print(magenta)

Tuples support indexing and iteration much like lists, but operations that would modify individual elements are not allowed. This makes the intention of fixed data explicit.

Dictionaries#

A dictionary stores key–value pairs. Unlike a list or array, which is usually accessed by numerical position, a dictionary is accessed by its keys. Keys are often strings, although other immutable types are also possible. Dictionaries use curly braces.

dictionary = {"key1": value1, "key2": value2, "key3": value3}

Dictionaries are particularly useful for data in which values have natural labels: properties of elements, information about molecular species, experimental conditions, or metadata associated with samples.

atomic_masses = {"H": 1.01, "He": 4.00, "Li": 6.94, "Be": 9.01}

print(atomic_masses["Li"])  # atomic mass of lithium

Exercise 6.1

Create one array containing the odd integers from 1 through 101 and another containing the even integers from 0 through 100. Add the arrays element by element.

Suggested solution

Exercise 6.2

A program evaluates c = a + b. Explain what happens in each case:

  1. a = [1, 2, 3, 4] and b = [1, 2, 3, 4]

  2. a = [1, 2, 3, 4] and b = 1

  3. a = np.array([1, 2, 3, 4]) and b = 1

  4. a = np.array([1, 2, 3, 4]) and b = np.array([1, 2, 3, 4])

Suggested solution

Two ordinary lists are concatenated with +. Adding a scalar directly to a Python list gives a TypeError. For a NumPy array, adding a scalar adds that number to every element, and adding two arrays of the same shape is performed element by element.

Exercise 6.3

A program evaluates c = a * b. Explain what happens when:

  1. a = [1, 2, 3, 4] and b = [1, 2, 3, 4]

  2. a = [1, 2, 3, 4] and b = 4

  3. a = np.array([1, 2, 3, 4]) and b = np.array([1, 2, 3, 4])

Suggested solution

Two ordinary lists cannot be multiplied directly. A list multiplied by an integer is repeated, so [1, 2] * 2 becomes [1, 2, 1, 2]. For NumPy arrays of the same shape, * performs element-wise multiplication.

Exercise 6.5

The code below calculates pH for several hydronium-ion concentrations using a loop. Vectorise the calculation.

import numpy as np
hydronium_values = [1E-10, 2.4E-9, 1E-8, 3.5E-7, 7E-6, 1.2E-5, 1E-4, 1E-2, 1.2]

def acidity(hydronium):
    return -np.log10(hydronium)

for concentration in hydronium_values:
    pH_values.append(acidity(concentration))

Suggested solution

import numpy as np
hydronium = np.array([1E-10, 2.4E-9, 1E-8, 3.5E-7, 7E-6, 1.2E-5, 1E-4, 1E-2, 1.2])
pH = -np.log10(hydronium)
print(pH)

NumPy applies log10 to the entire array, so no explicit loop is required.

Exercise 6.6

We have the vectors \(\vec{v}=[2,2]\) and \(\vec{w}=[1,-3]\). Determine whether the vectors are orthogonal by calculating their dot product. Check the result by hand.

Suggested solution

import numpy as np
v = np.array([2, 2])
w = np.array([1, -3])
dot_product = np.dot(v, w)
print(dot_product)

By hand, \(2\cdot1+2\cdot(-3)=-4\), so the vectors are not orthogonal.

Exercise 6.10

The variables below contain information about students and their teacher. Organise the same information in a dictionary instead. What is the advantage of doing so?

students = ["Gunnar", "Marius", "Kristian"]
teacher = "Andreas"

Suggested solution

One possible organisation is:

group = {
    "teacher": "Andreas",
    "students": ["Gunnar", "Marius", "Kristian"],
}
print(group["teacher"])
print(group["students"])

The keys make the meaning of the values explicit and allow related information to be stored as one structured object.

Exercise 6.11

Create a nested dictionary containing at least three chemical species and at least three properties for each species. Choose properties that make scientific sense and include units in the key names or associated text where appropriate.

Suggested solution

One possible example is:

species = {
    "H2O": {"molar_mass_g_mol": 18.015, "melting_point_C": 0.0, "boiling_point_C": 100.0},
    "CO2": {"molar_mass_g_mol": 44.01, "sublimation_point_C": -78.5, "formula": "CO2"},
    "NaCl": {"molar_mass_g_mol": 58.44, "melting_point_C": 801.0, "formula": "NaCl"},
}
print(species["H2O"]["molar_mass_g_mol"])

The exact properties may differ between species; in a real data set, the schema should be chosen deliberately and documented.
