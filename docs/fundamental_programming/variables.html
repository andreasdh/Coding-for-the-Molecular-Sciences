Variables and data types#

Learning outcomes

After working through this topic, you should be able to:

  1. run simple programs in a programming editor

  2. use variables to represent chemical quantities and units

  3. define and explain different data types: integers, floating-point numbers, strings, and Boolean values

  4. display output using the print function

  5. perform simple arithmetic in Python

  6. obtain input from the user of a program

  7. import and use libraries

  8. format output using f-strings

Variables#

One of the most fundamental ideas in programming is the variable. We will use variables in almost every program we write. A variable can store a value, for example a number, a piece of text, or a list containing many numbers.

When we write temperature = 298, we create a variable called temperature and assign it the value 298. Here the equals sign is an assignment operator: the value on the right is assigned to the variable on the left. This means that temperature = 298 is not a mathematical equation, but an instruction to the computer.

Variable

A programming variable is a named quantity that stores a value in a program.

Variable names can contain letters, numbers, and underscores, but they cannot begin with a number or contain spaces. Python is also case-sensitive, so temperature and Temperature are two different variables. Use names that communicate what a value represents. For example, HCl_concentration is more informative than simply x.

Variables are particularly useful when we need the same value several times or when we update a value while the program is running. In a chemistry program, a variable might represent a mass, temperature, concentration, or volume. If we add titrant in 1 mL increments, we might describe the process using pseudocode like this:

volume_added = 0
repeat 10 times:
    volume_added = volume_added + 1
    display volume_added on the screen

The value stored in volume_added is updated after each addition. The instruction volume_added = volume_added + 1 would make no sense as a mathematical equation, but in a program it means: retrieve the old value, increase it by 1, and store the result in the same variable. You can think of a variable as a labelled box whose contents can be retrieved and changed while the program runs.

What is pseudocode?

Pseudocode is a description of an algorithm that does not use a particular programming language. It can be written in many ways and may use words, diagrams, and symbols.

The Python code below calculates the amount of substance in four samples containing 2.922 g, 5.844 g, 8.766 g, and 11.688 g NaCl. What is the advantage of storing the molar mass in the variable NaCl_molar_mass?

Suggested answer

Print#

To get something out of a program, we need to ask the computer to display or “print” something. We do this with the print function. The result is shown in the console, the area where the programming environment displays output. If we want to print several variables or values, we separate them with commas. We can also perform calculations directly inside print. Here are a few examples:

print(n1)
print(n1, n2, n3, n4)
print("The amount of substance in sample 4 is:", n4, "mol.")
print(2 + 5/7 - 3*2.1 + 14.5**0.5)

Exercise

Write a program that calculates the concentration in mol/L when 0.10 mol of a substance is dissolved to make a total volume of 0.50 L. Print a sentence containing the answer and its unit.

Suggested solution

amount = 0.10  # mol
volume = 0.50  # L
concentration = amount / volume

print("The concentration is:", concentration, "mol/L")

Comments#

Comments are important for remembering what code illustrates, which units are being used, and what assumptions have been made. They are also valuable when other people need to understand or reuse your code. In chemical calculations, commenting units and assumptions is particularly useful because Python does not keep track of physical units for us.

A comment begins with #. If a comment spans several lines, each line should normally begin with #. Triple quotation marks can be used to create a multi-line string. Such a string at the beginning of a program or function can serve as documentation describing what the code does. Here is an example:

"""
Calculate the heat required to increase the temperature
of a water sample, neglecting heat loss.
"""

mass = 100.0              # mass of water in g
heat_capacity = 4.18      # specific heat capacity in J/(g*K)
temperature_change = 10   # temperature change in K

heat = mass * heat_capacity * temperature_change
print("The water sample absorbs", heat, "J.")

Arithmetic#

We can use Python as a simple calculator. Some of the most important operators are:

Operator

Meaning

+

Addition (a + b)

-

Subtraction (a - b)

*

Multiplication (a*b)

/

Division (a/b)

**

Exponentiation (a**b)

Python follows the usual order of operations: powers are evaluated before multiplication and division, which are evaluated before addition and subtraction. Use parentheses when you want to change the order or make an expression easier to read. For example, n*R*T/V and (n*R*T)/V give the same result, but the parentheses may make the relationship to a chemical formula clearer.

In program code we use a decimal point. The number 0.25 is therefore written as 0.25.

Exercise

Python also has two special operators, // and %. Find out what they do by experimenting in the editor below. Some starting lines have been provided, but you are free to explore.

Solution

// performs floor division. For positive integers, it gives the number of complete times the divisor fits into the dividend. Thus 24 // 5 = 4, because \(4\times5=20\). The remainder is 4. The % operator returns this remainder, so 24 % 5 is 4. The % symbol is called the modulus operator here and does not mean percentage.

Example from the chemistry laboratory

Suppose we have 24 mL of solution and want to fill sample vials with 5 mL in each. Because the volumes in this simplified example are whole millilitres, we can use floor division to find the number of full vials and modulus to find the remaining volume:

total_volume = 24       # mL
volume_per_vial = 5     # mL

number_of_full_vials = total_volume // volume_per_vial
remaining_volume = total_volume % volume_per_vial

print("We can fill", number_of_full_vials, "sample vials.")
print("There will be", remaining_volume, "mL of solution left.")

The program shows that we can fill four sample vials and that 4 mL remains. In the laboratory, volumes are often measured as decimal values, in which case ordinary division (/) is usually more relevant. Floor division and modulus are mainly useful when distributing a whole number of units or determining how much remains.

Libraries#

Many mathematical functions are not built directly into the Python language. To access functions such as sqrt, cos, and log, we import libraries or modules. Python has a standard library module called math, but in this material we often use NumPy because it can also perform calculations on many numbers at once. This becomes particularly useful when we later work with data sets and simulations.

There are several ways to import a library. Here are some ways to import the very useful NumPy library (numerical Python):

# Method 1: Import only the functions you need
from numpy import log10

H3O_concentration = 1E-7  # mol/L
pH = -log10(H3O_concentration)

# Method 2: Import the entire library
import numpy

R = 8.314       # J/(mol*K)
T = 298         # K
M_O2 = 0.032    # kg/mol
v_rms = numpy.sqrt(3*R*T/M_O2)

# Method 3: Import the library using an alias.
# This is the most common approach.
import numpy as np

A = 1E12        # pre-exponential factor in 1/s
E_a = 75000     # activation energy in J/mol
k = A*np.exp(-E_a/(R*T))

# Method 4: Import everything without specifying
# which library the functions come from
from numpy import *

pH = -log10(1E-7)
v_rms = sqrt(3*R*T/M_O2)

Exercise

Study the different import methods and explain how they differ.

Method 3 is the most common approach and the one we will use most often. Some older teaching videos use a star import from a collection called pylab (from pylab import *). It includes functionality from libraries such as NumPy and Matplotlib and was once used to simplify introductory code. Star imports, however, make it harder to see where functions originate, so we will mainly use method 3.

Consider the root-mean-square speed of gas molecules, \(v_{rms}\). It can be calculated from:

\[v_{rms}=\sqrt{\frac{3RT}{M}}\]

where \(R=8.314\) J mol\(^{-1}\) K\(^{-1}\), \(T\) is the temperature in K, and \(M\) is the molar mass in kg/mol.

Exercise

Write a program that calculates the RMS speed of oxygen molecules at 298 K. The molar mass of \(O_2\) is 0.032 kg/mol. Import only the sqrt function from NumPy. Could you perform the calculation without importing sqrt?

Suggested solution

from numpy import sqrt

R = 8.314    # J/(mol*K)
T = 298      # K
M_O2 = 0.032 # kg/mol

v_rms = sqrt(3*R*T/M_O2)
print("The RMS speed is:", v_rms, "m/s")

We could also write (3*R*T/M_O2)**0.5. In that case sqrt does not need to be imported, although the function makes the square root explicit.

User input#

We can ask the user of a program to enter values. This can be useful, for example, when the same program will be used to calculate the amount of substance for several samples with different masses. We obtain user input with the input function.

input always returns a text string. If the user enters a number that we want to use in calculations, we must convert the text to an integer or floating-point number. In the program below, float(input(...)) is therefore used to obtain the mass of NaCl. The program then calculates the amount of substance by dividing the mass by the molar mass:

NaCl_molar_mass = 58.44  # g/mol
mass = float(input("Mass of NaCl in g: "))

amount = mass / NaCl_molar_mass
print(mass, "g NaCl corresponds to", amount, "mol.")

Read the program line by line and explain what happens. What mass must the user enter for the program to return 0.10 mol NaCl? You can copy the code to a programming editor and try different masses. When the program runs, the user enters the value in the console.

User input is mainly useful for making programs interactive. If you create a program with input, it is usually best to add the input step only after the calculation itself works. Start by assigning fixed values to the variables and test the program. Then replace selected values with input. This avoids having to re-enter values every time you run code while debugging it.

Exercise

Modify the program that calculates the RMS speed of oxygen molecules so that the temperature in K is entered by the user. Remember to convert the input to a number.

Suggested solution

from numpy import sqrt

R = 8.314                 # J/(mol*K)
T = float(input("Temperature in K: "))
M_O2 = 0.032             # kg/mol

v_rms = sqrt(3*R*T/M_O2)
print("The RMS speed is:", v_rms, "m/s")

F-string formatting#

When we combine text and variables in printed output, we can separate them with commas as above. Another, often clearer method is a formatted string, usually called an f-string. Put the letter f before the opening quotation mark and write variables or expressions inside braces:

print(f"{mass} g {substance} corresponds to {amount} mol.")

Python replaces the contents of the braces with the values stored in the variables. This lets us write the complete sentence as one continuous string. We can also control how many decimal places are displayed.

substance = "NaCl"
mass = 2.922       # g
molar_mass = 58.44 # g/mol

amount = mass / molar_mass

print(f"{mass} g {substance} corresponds to {amount} mol.")
print(f"{mass:.2f} g {substance} corresponds to {amount:.3f} mol.")

In the second print statement, :.2f means that the value is displayed as a floating-point number with two decimal places, while :.3f gives three decimal places. Formatting changes only how the number is displayed, not the value stored in the variable. It is usually best to retain full precision during calculations and round only when presenting the result.

Exercise

Modify one of the programs you wrote earlier so that the result is printed using an f-string. Display the mass with two decimal places and the amount of substance with three decimal places.

Suggested solution

NaCl_molar_mass = 58.44  # g/mol
mass = float(input("Mass of NaCl in g: "))

amount = mass / NaCl_molar_mass
print(f"{mass:.2f} g NaCl corresponds to {amount:.3f} mol.")

Data types#

In mathematics we work with number sets such as real, rational, integer, natural, irrational, and complex numbers. Many of these sets contain infinitely many numbers, while a computer has finite storage. Python therefore uses different data types to represent numbers and other values. A floating-point number (float) is, for example, an approximate representation of a real number, so some calculations can produce small rounding errors. The most important data types here are:

Data type

Meaning

Example

Integer (int)

Whole number

number_of_C = 12

Floating-point number (float)

Decimal number

concentration = 0.10

String (str)

Text

substance = "NaCl"

Boolean (bool)

True or false

is_acidic = True

When we obtain input from a user, we need to consider which data type we want. The default is text. If we “add” the text strings "4" and "2", we obtain "42", whereas the number 4 plus the number 2 gives 6. The example below illustrates the difference.

text1 = input("Enter a number: ")
text2 = input("Enter another number: ")

number1 = float(text1)
number2 = float(text2)

text_result = text1 + text2
numeric_result = number1 + number2

print("The sum of the text strings is:", text_result,
      "and the sum of the numbers is:", numeric_result)

Exercise

Write a program that asks the user for the name of a chemical substance and its molar mass in g/mol. Store the answers in variables and print a sentence such as NaCl has a molar mass of 58.44 g/mol. What data type do the two variables have if you do not convert the input? Then modify the program so that the molar mass is stored as a floating-point number.

Suggested solution

substance = input("What is the substance called? " )
molar_mass = float(input("What is its molar mass in g/mol? "))

print(substance, "has a molar mass of", molar_mass, "g/mol.")

Input is initially stored as text (str). The float function converts the molar mass to a floating-point number. Use a decimal point when entering numbers in Python.

Computers require precise instructions#

When you create programs in Python, remember the following:

  • The program is read from top to bottom and from left to right.

  • Lower-case and upper-case letters are different (p \(\neq\) P).

  • Python usually ignores extra spaces, except at the beginning of a line where indentation matters. Use spaces to make code readable.

  • Python does not know whether a number represents grams, litres, or mol/L. Use clear variable names and comments to keep track of units.

  • Practise reading error messages: they usually identify the line involved and the type of error.

Exercise

Explain what is wrong with each of the following programs:

number1 = 1
print(number1 + number2)
number2 = 3

name = "Gunnar"
print(Name)

a = 2
b = 3

print("The difference between" a "and" b "=" a + b)

Suggested answers

  1. The program is read from top to bottom. number2 must therefore be defined before it is used in the addition. Lines 2 and 3 need to exchange places.

  2. The variable name begins with a lower-case n. The variable Name does not exist.

  3. We need commas between all items in the print function. In addition, the text should say “sum”, not “difference”.

print("The sum of", a, "and", b, "=", a + b)

Exercise 1.7

An electron and a proton in a hydrogen atom are influenced primarily by electrostatic and gravitational forces. The magnitude of the electrostatic force is described by Coulomb’s law, \(F_e=k_e|q_1q_2|/r^2\), and the gravitational force by Newton’s law of gravitation, \(F_g=Gm_1m_2/r^2\). Use \(k_e=8.987742438\times10^9\) N m\(^2\) C\(^{-2}\), \(e=1.602176634\times10^{-19}\) C, \(G=6.674\times10^{-11}\) N m\(^2\) kg\(^{-2}\), \(r=5.292\times10^{-11}\) m, \(m_p=1.672\times10^{-27}\) kg, and \(m_e=9.109\times10^{-31}\) kg.

a) Store all constants in clearly named variables and document their meanings and units with comments. b) Calculate the electrostatic and gravitational forces. c) Print their ratio with a descriptive sentence. What does the result tell you? Add your interpretation as a multi-line comment at the end of the program.

Suggested solution

k_e = 8.987742438E9  # Coulomb constant in N*m^2/C^2
q = 1.602176634E-19  # elementary charge in C
G = 6.674E-11        # gravitational constant in N*m^2/kg^2
r = 5.292E-11        # approximate proton-electron distance in m
m_p = 1.672E-27      # proton mass in kg
m_e = 9.109E-31      # electron mass in kg

F_e = k_e*q*q/r**2
F_g = G*m_p*m_e/r**2
ratio = F_e/F_g
print("The ratio of electrostatic to gravitational force is:", ratio)

"""
The electrostatic force is enormously larger than the gravitational force.
For systems containing only a few atoms or molecules, gravity can therefore
normally be neglected.
"""

Calculate the absorbance for \(\varepsilon=1.50\times10^4\) L mol\(^{-1}\) cm\(^{-1}\), \(l=1.00\) cm, and \(c=2.50\times10^{-5}\) mol/L. Use descriptive variable names and comments with units. Exercise 1.9

For an ideal gas, \(pV=nRT\). Write a program that calculates the pressure in bar for \(n=0.050\) mol, \(T=25.0\) °C, and \(V=1.50\) L, using \(R=0.08314\) L bar mol\(^{-1}\) K\(^{-1}\). Remember to convert the temperature to kelvin. Then modify the program so that the Celsius temperature is entered by the user. Why is it useful to keep both temperature_celsius and temperature_kelvin as variables?

Suggested solution

amount = 0.050              # mol
temperature_celsius = 25.0  # degrees Celsius
volume = 1.50               # L
gas_constant = 0.08314      # L*bar/(mol*K)

temperature_kelvin = temperature_celsius + 273.15
pressure = amount*gas_constant*temperature_kelvin/volume
print("The pressure is:", pressure, "bar")

With user input:

temperature_celsius = float(input("Temperature in degrees Celsius: "))

Keeping two variables makes the temperature scale explicit and reduces the risk of using degrees Celsius directly in the ideal-gas equation.
