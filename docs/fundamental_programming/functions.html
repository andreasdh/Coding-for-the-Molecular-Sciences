Functions#

Learning outcomes

After working through this topic, you should be able to:

  1. use functions to structure and reuse code

  2. explain the difference between a parameter and an argument

  3. use return to retrieve values from a function

  4. explain what is meant by local and global variables

  5. use functions to represent chemical relationships and calculations

Definition#

In addition to built-in Python functions such as print and input, we can define our own functions. This makes programs easier to organise and is particularly useful when we need to perform the same type of calculation several times.

Chemistry constantly uses relationships that take some quantities as input and produce a new quantity. From mass and molar mass we can find amount of substance; from hydronium-ion concentration we can find pH; and from pressure, volume, and temperature we can use the ideal-gas equation to calculate amount of substance. Such relationships are naturally represented as functions.

We begin with

\[n=\frac{m}{M},\]

where \(n\) is the amount of substance in mol, \(m\) is the mass in grams, and \(M\) is the molar mass in g/mol.

def amount_in_moles(mass, molar_mass):
    amount = mass / molar_mass
    return amount

The keyword def defines a function. Here the function is called amount_in_moles. The names in parentheses, mass and molar_mass, are parameters. Everything belonging to the function is indented.

return specifies the value that the function gives back. We can store that value in a variable or use it directly in another calculation. Merely defining a function produces no visible result; we must call it.

def amount_in_moles(mass, molar_mass):
    amount = mass / molar_mass
    return amount

moles_NaCl = amount_in_moles(5.85, 58.44)
print(f"The amount of NaCl is {moles_NaCl:.3f} mol.")

# We can also call the function directly inside print:
print(amount_in_moles(5.85, 58.44))

The numbers 5.85 and 58.44 are arguments. When the function is called, these values are passed to the parameters mass and molar_mass. Parameters are therefore the names used in the function definition, whereas arguments are the actual values supplied in a function call.

Create a function that calculates concentration, \(c=n/V\). The function should take amount of substance in mol and volume in litres as parameters. Use it to find the concentration when 0.15 mol of solute is present in 0.50 L of solution.

return and print#

A function does not have to return a value. It can, for example, only print something:

def print_amount(mass, molar_mass):
    amount = mass / molar_mass
    print(f"The amount of substance is {amount:.3f} mol.")

print_amount(5.85, 58.44)

Here we do not need print when calling the function because printing occurs inside it. Why, then, do we usually prefer return for calculated quantities?

If the result is needed later, the function must return a value. Printed output is text displayed to the user; it is not a numerical result that another part of the program can use. This program works because both function calls return numbers:

def amount_in_moles(mass, molar_mass):
    return mass / molar_mass

moles_NaCl = amount_in_moles(5.85, 58.44)
moles_KCl = amount_in_moles(7.46, 74.55)

total_amount = moles_NaCl + moles_KCl
print(total_amount)

A function without an explicit return returns the special value None. As a general rule, it is therefore useful to return calculated values and decide separately how they should be displayed.

Functions with several parameters#

A function can have as many parameters as it needs. For an ideal gas,

$$P=\frac{nRT}{V}.

def ideal_gas_pressure(amount, temperature, volume):
    R = 8.314  # J/(mol K)
    pressure = amount * R * temperature / volume
    return pressure

# Function call 1: the arguments are numerical values
print(ideal_gas_pressure(0.10, 298.15, 0.0025))

# Function call 2: the arguments are variables
n = 0.10
T = 298.15
V = 0.0025
P = ideal_gas_pressure(n, T, V)
print(f"The pressure is {P/1000:.1f} kPa.")

Variables outside the function do not need the same names as its parameters. With positional arguments, order determines where the values go: the first argument is assigned to amount, the second to temperature, and the third to volume. Clear scientific names nevertheless make code easier to read.

Functions with several return values#

Unlike a mathematical function in the elementary sense, a programming function can return several values. During a dilution, for example, we can calculate both the final concentration and the dilution factor.

def dilution(initial_concentration, initial_volume, final_volume):
    final_concentration = initial_concentration * initial_volume / final_volume
    dilution_factor = final_volume / initial_volume
    return final_concentration, dilution_factor

c2, factor = dilution(0.50, 10.0, 100.0)

print(f"The final concentration is {c2:.3f} mol/L.")
print(f"The solution has been diluted by a factor of {factor:.0f}.")

The returned values are assigned to c2 and factor in the same order in which they appear after return.

Exercise

Explain how the program above works. Extend the function so that it also returns the amount of dissolved solute. Assume that the volumes are given in mL. Print all three results using f-strings.

Suggested solution

def dilution(initial_concentration, initial_volume, final_volume):
    final_concentration = initial_concentration * initial_volume / final_volume
    dilution_factor = final_volume / initial_volume
    amount = initial_concentration * initial_volume / 1000
    return final_concentration, dilution_factor, amount

c2, factor, n = dilution(0.50, 10.0, 100.0)
print(f"Final concentration: {c2:.3f} mol/L")
print(f"Dilution factor: {factor:.0f}")
print(f"Amount of substance: {n:.4f} mol")

Local and global variables#

Variables defined inside a function are available only inside that function and are called local variables. Function parameters are local as well. Variables defined outside functions are global variables.

R = 8.314  # global variable

def ideal_gas_pressure(n, T, V):
    pressure = n * R * T / V  # local variable
    return pressure

P = ideal_gas_pressure(0.10, 298.15, 0.0025)
print(P)

Here R is global and can be read both outside and inside the function. The parameters n, T, and V, and the variable pressure, are local. P is global because it is created outside the function. What happens if we try to use the local variable pressure outside the function?

R = 8.314

def ideal_gas_pressure(n, T, V):
    pressure = n * R * T / V
    return pressure

P = ideal_gas_pressure(0.10, 298.15, 0.0025)
print(pressure)  # raises NameError

We obtain an error even though pressure is visibly defined in the function. The variable exists only locally while the function is executing. Its value is nevertheless available outside because the function returns it and we store it in P.

Python has a global keyword that can be used to modify a global variable inside a function. It is rarely necessary and often makes changes to program state harder to follow. Passing values in as arguments and returning results is usually clearer, easier to test, and easier to reuse.

Default parameter values#

Sometimes a parameter usually has one value but should remain adjustable. We can then give it a default. In measured data it is rarely sensible to demand that two floating-point values be exactly equal, so we might ask whether a measured pH lies within a chosen tolerance around 7.

def is_neutral(pH, tolerance=0.1):
    return 7 - tolerance <= pH <= 7 + tolerance

print(is_neutral(7.05))       # uses the default value 0.1
print(is_neutral(7.15, 0.2))  # uses a tolerance of 0.2

Parameters with default values are normally placed after required parameters. The function can be called either with or without a separate argument for tolerance.

    return amount * molar_mass

mass_NaCl = mass(0.20, 58.44)

Exercise 5.2

The Beer–Lambert law is \(A=\varepsilon lc\). Create a function that takes molar absorptivity, path length, and concentration as parameters and returns absorbance. Test it with \(\varepsilon=4700\) L/(mol cm), \(l=1.00\) cm, and \(c=2.5\times10^{-5}\) mol/L.

Suggested solution

def absorbance(epsilon, path_length, concentration):

A = absorbance(4700, 1.00, 2.5E-5)

Exercise 5.9

Create one function that calculates absorbance using the Beer–Lambert law and another that calculates concentration from measured absorbance. Check that the functions are consistent by passing the result from the first into the second.

Suggested solution

def absorbance(epsilon, path_length, concentration):
    return epsilon * path_length * concentration
def concentration(absorbance_value, epsilon, path_length):
    return absorbance_value / (epsilon * path_length)
c_initial = 2.5E-5
A = absorbance(4700, 1.00, c_initial)
c_calculated = concentration(A, 4700, 1.00)
print(f"Absorbance: {A:.4f}")

Exercise 5.10

The energy of an electron in level \(n\) of a hydrogen atom is \(E_n=-B/n^2\), where \(B=2.18\times10^{-18}\) J. Create one function for the energy of a level and one for the wavelength of a photon emitted during a transition from \(n\) to lower level \(m\). Use \(|\Delta E|=hc/\lambda\), \(h=6.626\times10^{-34}\) J s, and \(c=3.00\times10^8\) m/s. Test the transition from \(n=3\) to \(m=2\).

Suggested solution

B = 2.18E-18
h = 6.626E-34
c = 3.00E8
def energy_level(n):
    return -B / n**2
def wavelength(n, m):
    delta_E = energy_level(n) - energy_level(m)
    return h * c / abs(delta_E)
wavelength_nm = wavelength(3, 2) * 1E9
print(f"The wavelength is {wavelength_nm:.0f} nm.")

Exercise 5.11

Create a function that takes the initial and final amounts of a reactant and returns both the amount consumed and the percentage conversion. Test it with 0.250 mol initially and 0.040 mol finally.

Suggested solution

def conversion(initial_amount, final_amount):
    amount_consumed = initial_amount - final_amount
    conversion_percent = amount_consumed / initial_amount * 100
    return amount_consumed, conversion_percent
consumed, percent = conversion(0.250, 0.040)
print(f"Amount consumed: {consumed:.3f} mol")
print(f"Conversion: {percent:.1f} %")

Exercise 5.12

Why does the global variable concentration have the same value before and after the function call?

def dilute(concentration):
    concentration = concentration / 10
    return concentration
concentration = 0.50
new_concentration = dilute(concentration)
print(concentration)
print(new_concentration)

Suggested solution

The parameter concentration inside the function is local even though it has the same name as the global variable. The local value is changed and returned, while the global variable remains 0.50 mol/L.

Exercise 5.13

Most gases can often be approximated using \(PV=nRT\). Create one function for pressure and another for temperature. Use SI units and test them with realistic values.

Suggested solution

R = 8.314
def pressure(amount, temperature, volume):
    return amount * R * temperature / volume
def temperature(pressure_value, volume, amount):
    return pressure_value * volume / (amount * R)
P = pressure(1.00, 298.15, 0.0245)
T = temperature(P, 0.0245, 1.00)
print(f"Pressure: {P/1000:.1f} kPa")
print(f"Temperature: {T:.2f} K")

Exercise 5.14

Study the program. Which variables are local and which are global? What is printed?

R = 8.314
def volume(amount, temperature, pressure):
    calculated_volume = amount * R * temperature / pressure
    return calculated_volume
n = 1.00
T = 298.15
P = 101325

Exercise 5.15

Create a function that takes \([H_3O^+]\) and an optional tolerance. It should return both pH and the text acidic, neutral, or basic. Use a default tolerance of 0.1 pH units and test \(1.0\times10^{-5}\), \(1.1\times10^{-7}\), and \(1.0\times10^{-9}\) mol/L.

Suggested solution

import numpy as np
def classify_solution(hydronium, tolerance=0.1):
    pH = -np.log10(hydronium)
    if pH < 7 - tolerance:
        description = "acidic"
    elif pH > 7 + tolerance:
        description = "basic"
    else:
        description = "neutral"
    return pH, description
for concentration_value in [1.0E-5, 1.1E-7, 1.0E-9]:
    pH_value, solution_type = classify_solution(concentration_value)
    print(f"pH = {pH_value:.2f}: {solution_type}")

Exercise 5.16

For a buffer pair HA/A\(^-\), \(pH=pK_a+\log_{10}([A^-]/[HA])\). Create a function taking \(pK_a\), acid concentration, and base concentration as parameters. Test an acetic acid/acetate buffer with \(pK_a=4.76\), \([CH_3COOH]=2.3\times10^{-3}\) mol/L, and \([CH_3COO^-]=2.0\times10^{-3}\) mol/L.

Suggested solution

import numpy as np
def buffer_pH(pKa, acid, base):
    return pKa + np.log10(base / acid)
pH_value = buffer_pH(4.76, 2.3E-3, 2.0E-3)
print(f"The buffer pH is {pH_value:.2f}.")

Exercise 5.17

For a simple calorimetric calculation, \(q=mc\Delta T\). Create a function taking mass, specific heat capacity, initial temperature, and final temperature. Return both \(q\) and \(\Delta T\).

Suggested solution

def heat_absorbed(mass, heat_capacity, initial_temperature, final_temperature):
    delta_T = final_temperature - initial_temperature
    q = mass * heat_capacity * delta_T
    return q, delta_T
q, delta_T = heat_absorbed(100.0, 4.18, 20.0, 27.5)
print(f"Temperature change: {delta_T:.1f} °C")
print(f"Heat absorbed: {q:.0f} J")

Exercise 5.18

Create a function valid_concentration that returns True if a concentration is greater than 0 and False otherwise. Use it in a new pH function that performs the calculation only for valid concentrations. What should the function return when the value is invalid?

Suggested solution

import numpy as np
def valid_concentration(concentration):
    return concentration > 0
def pH(hydronium):
    if not valid_concentration(hydronium):
        return None
    return -np.log10(hydronium)
print(pH(1.0E-5))
print(pH(0))

None is a natural return value when no numerical result can be produced. In a larger program, it may instead be appropriate to raise a clear exception such as ValueError.
